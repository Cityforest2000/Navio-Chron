# Navio-Chron

Navio Chron is an open-source keypad that controls CapCut video editor just like Tourbox. The current v1 is a pure HID keyboard/mouse build. Later versions will use HID Vendor descriptors with a Python background service for easier key remapping, and support drawing apps on iPad.
