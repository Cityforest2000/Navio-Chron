# Navio-Chron

Navio Chron is an open-source keypad that controls CapCut video editor just like Tourbox. The current v1 is a pure HID keyboard/mouse build. Later versions will use HID Vendor descriptors with a Python background service for easier key remapping, and support drawing apps on iPad.

# About Firmware
A fantastic independent firmware developed by a Bilibili Elvin for the open-source Navio Chron editing keyboard. Built on ESP32-S3, it supports dual-mode USB/Bluetooth connectivity, multiple dynamic profiles, and a complete browser-based toolchain for firmware flashing, key mapping configuration, and OTA updates — all without requiring any software installation on the host computer.

Preset Editor: https://isilcala.github.io/Navio-Chron-Firmware/

Firmware Flashing & Updates: https://isilcala.github.io/Navio-Chron-Firmware/firmware/
